# Codebook

Description of the raw data, the experiment files and the derived data in this
repository. Paths are relative to the repository root.

## Raw data

`experiment/data/*.csv` and `experiment_mid_lab/data/*.csv`: one file per
session and task, written by PsychoPy. The two folders are the two lab setups
(see `experiment/object_triplets.psyexp` and
`experiment_mid_lab/object_triplets_mid_lab.psyexp`). 92 files.

File names: `{task}_{observer}_{session}_object_triplets_{date}_{lastblock}.csv`

| Part | Values |
|---|---|
| `task` | `classic` or `odd one out` |
| `observer` | `O1` - `O5` (Experiment 1) and `P1`, `P2` (Experiment 2). P1 is the same person as O5. |
| `session` | Triplet set (`1` - `9`) and shuffle (`a`, `b`, ...), e.g. `1a`. A suffix `2` (`1b2`, `5a2`) marks the second part of a session that was split because the experiment crashed. |
| `date` | Start of the session, `YYYY-MM-DD_HHhMM.SS.mmm` (Europe/Berlin). |
| `lastblock` | Last block completed, as written by the experiment. |

Each row is one trial. The columns used by the analysis:

| Column | Meaning |
|---|---|
| `participant` | Observer code, as in the file name. |
| `experiment` | Task, `classic` or `odd one out`. |
| `session`, `date` | As in the file name. |
| `image_set` | `action`, `greebles` or `taxonomic`. |
| `triplet_index` | Identifier of the triplet (row of the condition file). |
| `block_number` | Block of 150 trials; `0` marks training trials. |
| `image1`, `middle`, `image2` | File names of the three images. |
| `image1_index`, `middle_index`, `image2_index` | Their indices (0 - 17) in `resources/{image_set}_info.csv`. |
| `is_left` | `1` if `image1` was shown on the left and `image2` on the right, `2` if swapped. |
| `resp.key` | Button pressed: `green` (left), `red` (right) and, in the odd-one-out task, `yellow` (top). Empty if no response was recorded. |
| `resp.rt` | Response time in seconds. There was no time limit. |
| `repetition` | Shuffle of the triplet set (as in `session`). |

Display: in both tasks `middle` is shown at the top centre and `image1` and
`image2` below it, on the left and right as given by `is_left`. In the
classic task `middle` is the reference, and the observer chooses which of the
two other images is more similar to it. In the odd-one-out task, the observer
chooses the image that does not belong.

The remaining columns are PsychoPy bookkeeping (loop counters, onset times,
mouse and keyboard states) and are not used.

`scripts/load_data.py::load_all()` reads all files and returns one row per
session, task and image set. It drops training trials and trials without a
response (counted in `n_timeout`), drops the first trial of every block
(a duplicate that only holds the break timing), merges the two parts of split
sessions, corrects the responses for the left-right swap, swaps the `green`
and `red` responses of observer O3 in session `1e` (classic task), whose
buttons had been swapped, and converts the responses into triplets. Its
columns:

| Column | Meaning |
|---|---|
| `observer`, `task`, `image_set`, `session`, `date` | As above. |
| `triplet_set`, `shuffle` | The two parts of `session`. |
| `raw_triplets` | Image indices per trial, as `[middle, image1, image2]` (classic) or `[image1, middle, image2]` (odd one out), before the left-right correction. |
| `raw_responses` | Buttons pressed. |
| `responses` | Responses corrected for the left-right swap: `1` or `-1` (classic; `1` means `image1` was chosen as more similar), `0`, `1` or `2` (odd one out; position of the odd image in `raw_triplets`). |
| `embedding_ready_triplets` | Triplets `(anchor, closer, farther)` as image indices: one per classic trial, two per odd-one-out trial. |
| `triplet_index`, `block`, `rt` | Per trial. |
| `n_trials`, `n_triplets`, `n_timeout`, `mean_rt` | Per session. `n_timeout` counts trials without a response. |
| `file` | Source file. |

`data/original_session_order.txt` fixes the order in which the session files
are combined, which decides the cross-validation folds; `load_all()` applies
it.

## Experiment materials

| Path | Content |
|---|---|
| `experiment/object_triplets.psyexp`, `experiment_mid_lab/object_triplets_mid_lab.psyexp` | PsychoPy Builder experiments of the two lab setups. |
| `experiment*/conditions/triplets_3x18_session{s}{r}.csv` | Trials of triplet set `s` (1 - 9) in shuffle `r`: the columns `triplet_index` to `is_left` of the raw data, plus `session_number` and `repetition`. Generated by `scripts/create_conditions.ipynb`. |
| `experiment*/conditions/training.csv` | Training trials. |
| `experiment*/images/` | Stimuli (see [STIMULI.md](STIMULI.md)). |
| `resources/action_info.csv` | Per image: `File_name`, `Object`, `Numerosity`. |
| `resources/taxonomic_info.csv` | Per image: `File_name`, `Object`, `Category`, `Genus`. |
| `resources/greebles_info.csv` | Per image: `File_name`, `Family`, `Gender`, `Individual`, `Angle` (view 1 or 2), `same_individual` (1 if the individual appears in two views). |
| `resources/greebles36_info.csv` | The same for all 36 greeble files, of which 18 were used. |
| `resources/taxonomic_colour_dictionary.txt` | Colours of the taxonomic categories in the figures. |
| `resources/things_images.csv` | THINGS images: `file_name`, `things_path` (path in the THINGS archive), `sha256`. |
| `resources/Similarity_of_natural_images_intro_video.mp4` | Instruction video shown before the first session. |

The order of the images in each `*_info.csv` defines the image indices used
everywhere else.

## Derived data (`data/`)

Embeddings and triplets are stored in the CSV files as text; read an
embedding with `np.array(ast.literal_eval(value))`.

| File | Content |
|---|---|
| `found-dimensionality-embeddings-aggregated-per-observer-nsplit-5-nrepeat-30.csv` | One row per observer, task and image set: all triplets of the condition (`embedding_ready_triplets`, `raw_triplets`, `responses`, `triplets`), number of triplets `Nt`, estimated `dimensionality` and the fitted `embedding` (18 x `dimensionality`). The task `odd-one-out-oneoftwo` (one of the two triplets of every odd-one-out trial) is not reported in the article. |
| `found-dimensionality-embeddings-pooled-observers-nsplit-5-nrepeat-30.csv` | The same for the data of O1 - O5 pooled (`observer` = `pooled O1 - O5`). |
| `*-LogOdds.csv` | The same tables with the dimensionality under the effect size criterion. |
| `triplet_accuracy_vs_dimensionality-{observer}-{task}-{image_set}.json` | Cross-validation of one condition: `dimensions` (1 - 5), `train_scores` and `test_scores` (triplet accuracy, 5 dimensions x 150 folds: 5 splits x 30 repeats), `estimated_dimension`, and `stats_result` with the tests between successive dimensions (`tstats`, `pvals`, `pvals_corrected` (Holm), `reject`, `effectsize`, `alpha`, `alpha_corrected`, `step`). `_LogOdds` files: the same under the effect size criterion. These files hold the reported dimensionalities. |
| `found-dimensionality-embeddings-design-{A,B,C}-draws.csv` | Pooling designs A, B and C: one row per draw (or dataset) and condition, with the `seed`, the pooled triplets, their origin (`source_observer`, `source_session`, `triplet_index`), `n_trials`, `n_triplets`, `dimensionality` and `embedding`. Design C also has `variant` (`single`: one observer, `mix`: five observers), `answered_by` and `combination` (the two sessions joined). |
| `triplet_accuracy_vs_dimensionality-design-*.json` | Cross-validation of every pooled dataset, as above. |
| `subsampling_analysis-{observer}-{task}-{image_set}-{runs}.csv` | Experiment 2 subsampling: per random run (`random-run`) and subsample size `n` (trials), the estimated dimensionality `d` and the triplet `accuracy` on the held-out triplets. |
| `subsampling_analysis-triplet_accuracy_alldata.csv` | Experiment 2 reference: dimensionality `d`, in-sample `accuracy` and number of trials `n` of the full data. |
| `simul_design_error.csv` | Simulation of the trial sampling design: per simulation `nsim`, ground truth (`distribution-gt`: `uniform` or `gaussian`), response noise, design (`as intended` or `as it was`) and `metric` (`RMSE`, `SD` or `range` of the embedding error), the `value`. |
| `dimensionality_seed_stability_published_inputs.csv` | Refits of the three seed-dependent conditions: which seed was varied (`vary`: `soe` initialisation or `cv` splits), the seeds, the estimated `dimensionality` and the p-values of the tests between dimensions. |
| `questionnaire_extracted_criteria.txt` | Criteria the observers named in the questionnaires after each session: `participant`, `criterion`, image `set`, `additional_info`. |
